### 🏚 [Ancestra](https://github.com/KyomuTenshi/Ancestra-DevBuild) — diploma project
First-person psychological horror / walking simulator about grief, guilt and memory. The player returns to a family home that keeps changing and uncovers an unfinished testament.

- Prototype made at **Punkverse Game Jam SU 2025**, then developed solo as my diploma project
- Structure: a prologue and five zones based on the five stages of grief, each zone adds one new mechanic
- Systems in C#: type-safe event bus, save system with atomic writes, checksums and version migration, localization with plural forms, audio with crossfades and SFX pooling, first-person controller with a fear system
- **Stack:** Unity 2022.3 LTS (URP), C#, Input System, TextMeshPro
- **Status:** MVP in development
- <sub>3D models: pizzadoggy asset pack. Music is not my own.</sub>
